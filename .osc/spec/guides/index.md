# Guides

These are reusable checklists and reference notes that sit between the high-level project spec and task-specific change packages.

## Available Guides

- [Cross-Layer Change Checklist](./cross-layer-change-checklist.md): use before changing API behavior, config persistence, auth flow, or UI contracts that span more than one package group.

## When To Add A Guide

Add a guide here when the same questions keep coming up across tasks, for example:

- compatibility and rollback checks
- auth-flow safety checks
- config migration or persistence rules
- release/build verification steps
