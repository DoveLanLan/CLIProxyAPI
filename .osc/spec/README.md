# `.osc/spec/`

This directory holds living repository knowledge for CLIProxyAPI.

## What Lives Here

- product and architecture baseline
- package boundaries and reuse rules
- persistence, logging, and error-handling conventions
- UI/TUI integration notes
- reusable change checklists

## Reading Order

1. `project-spec.md`
2. `shared/index.md`
3. `backend/index.md` or `frontend/index.md` depending on the task
4. `guides/` when the change crosses layers or needs a checklist

## Rule

If a rule or pattern will be reused across more than one task, write it here instead of leaving it in chat.
